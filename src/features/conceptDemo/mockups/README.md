# Demo home mockups

Store each home design exploration in its own numbered folder here.

- `home01/HomeMockup01.jsx`: spacious typography, a floating summary panel, and three cards over the shared gradient background.

These are visual studies with placeholder content, separate from live demo data and module actions. Open the first design using **Home mockup 01** in the demo home's three-dot menu. **Back to demo home** returns to the existing screen without resetting its React state. The appearance toggle shares the app's saved light/dark preference.
